How the model works

Each protocol's implied value starts from its TVL, times the peer multiple: the median market-cap-to-TVL ratio of live tokens in the same category (at least three peers, else the median over all live tokens), clamped to 0.05–1.5. Growth is the seven-day TVL change, clamped to −60%…+150%, weighted 0.6. Maturity rises with the days the protocol has run with no token on record, from 0.6 at day zero to 1.0 at three years; an unknown listing date counts as 365 days. No protocol name is special-cased, and the live-token protocols are set aside with their market caps shown — the board ranks only protocols with no token on record.

An implied value is the model's claim, not a price and not a promise that a token is issued.
